Developer details

Home-screen grid: recorded 11 Oct 2026 from icon centres on a 3200 × 2136 px screenshot (docs/decisions/ADR-005-home-grid.md); columns from x = 570 px every 411.5 px, rows from y = 320 px every 413 px. Stored as the homeScreen block of device-facts.json (docs/device/home-grid.json). PadStudio can't read the live grid.

HyperOS links: com.miui.home.Setting (Home screen settings) and com.miui.home.action.ICON_CUSTOMIZE (Background colour).

Widgets set to Default: 42 (Wide, GroupWidgetReceiver) and 49 (Large, GroupWidgetLargeReceiver); neither has a grid key.

Fit rule: every space at least 48 × 48 dp; usable width = widget − 20 dp; usable height = widget − 20 − 28 dp header. The preview is an example widget of 472 × 252 dp until the tablet reports real sizes.
